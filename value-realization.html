Solution Overview

Specialist Data Model: dbt-governed mart layer unifying specialist engagement data across all sources

A dbt project on Snowflake that transforms raw data from Salesforce, Pigment, SE Reporting, and Sigma into clean, tested mart tables tracking specialist engagement, org structure, account mapping, and use case pipeline for the AMS AFE and Architect teams.

Business Challenge
Raw specialist data fragmented across five source systems with no shared model
  • Salesforce, Pigment, SE Reporting, and Sigma each hold specialist data with no consistent join keys or shared schema
  • Dashboards built directly on raw tables break when upstream schemas change and produce inconsistent metrics across teams
  • No lineage documentation means data quality issues are traced manually and fixed in multiple places simultaneously
Snowflake Capabilities
dbt staging-intermediate-mart pipeline deployed on Snowflake compute
dbt Data Pipeline Dynamic Tables Streamlit in Snowflake
Business Outcomes
Stable, testable data foundation powering all specialist analytics
🎯
Single Source of Truth Seven mart models cover every specialist reporting use case — org, accounts, Pigment, requests, use cases, attribution, and engagement status
🔒
Schema-Isolated Consumers Dashboards and skills query mart tables, not raw sources — upstream schema changes are absorbed in staging, not propagated
🛠️
Auditable Lineage and Tests dbt tests and lineage docs mean data quality issues are caught at build time and traced to the exact staging model
